# Prompts de las animaciones

Generadas con el editor de imágenes integrado a partir del búho de referencia. Se ensamblaron y alinearon los fotogramas para la web.

## parpadeo

Use case: precise-object-edit. Input image is the exact character reference: the purple pixel-art owl with enormous golden eyes, cyan feather tips, orange beak and feet. Create a production animation sprite sheet of this SAME owl, preserving the reference identity, colors, proportions, soft pixel-art texture, head tilt, camera angle and lighting. Output one image in an exact 3-column by 2-row grid of SIX equal square cells (e.g. 1536 by 1024 total). Read cells left to right then top to bottom. Every cell has the whole owl, equal scale, equal baseline and identical center position. Each owl fits entirely within its cell with at least 12% padding; avoid cropping any feathers or feet. Background genuinely transparent, no checkerboard pixels, no grid lines, no borders, no numbers, no labels or text. Keep all unanimated parts unchanged across frames. Do not add props or shadows. Animate ONE natural blink. Frame1 eyes fully open, frame2 eyelids half lowered, frame3 both eyes fully closed with curved dark eyelid lines, frame4 eyes fully closed, frame5 eyes half open, frame6 same open-eyed resting pose as frame1. Head/body/wing position and camera MUST stay fixed. Expression sweet. No extra eyes or dark glasses.
